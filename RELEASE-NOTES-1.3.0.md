# FoxyPDF v1.3.0 Final

Pure offline PDF reader & annotator for Windows.

## Download

- **Windows 10/11 (64-bit):** `FoxyPDF Setup 1.3.0.exe` attached below.
- **Linux & macOS:** coming in **v1.4.0** with new additions.

## Highlights

- 🦊 New identity: Lector → FoxyPDF, with a brand-new fox logo, icons and installer branding
- 🎨 13 color themes + 6 accent colors, themed menu bar, saved locally
- 🌙 Night reading mode (`N` key): white pages turn black — easy on the reader's eyes
- 🖍 Rebuilt annotation toolbar: highlight, rectangle, cover, freehand pen, write-over text, image stamps, eraser, undo
- 🗂 Page organizer: delete pages (with confirm), drag to reorder, rotate 90°, multi-select, real undo
- 🔖 Bookmarks (`Ctrl+B`) + last-page resume, stored per file
- 🕘 Recent files panel + last-folder memory
- 📥 Drag & drop any PDF onto the window to open it
- 💾 Smart save: `Ctrl+S` overwrites with an automatic `.bak.pdf` backup; Save As creates `*-MODIFIED.pdf`
- 🌍 Full Arabic support (Noto Sans Arabic interface font, RTL text shaping)
- 🛠 Improved installer: choose install folder, optional desktop shortcut, Start Menu entry, PDF file association

## Notes

- 100% offline: no accounts, no cloud, no data collection.
